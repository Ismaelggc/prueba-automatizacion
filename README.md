# PRUEBA DE AUTOMATIZACIÓN  
Este repositorio se usará para probar las funciones de automatización de GitHub.  

Se van a hacer diferentes commits confusos usando este archivo para ejecutar un rebase.

Esto nos va a permitir cambiar el mensaje de estos commits para otrs que clarifiquen que se ha hecho realmente y sea útiles para el resto de personas que quieran usar el repositorio.
